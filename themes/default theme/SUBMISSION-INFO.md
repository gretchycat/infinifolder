# Infinifolder supported types icon collection

665 original, hand-authored SVG icons for file extensions, URI schemes, and directories, plus 10 unbadged base fallback SVGs.

File and URI icons use a category pictogram with an uppercase extension or scheme on a colored label. The palette matches the app's runtime fallback icons. Folder variants use only a pictogram stamp, without a text description plaque. Unbadged base fallback artwork is also included in `svg/` with `base-fallback-` filenames. `metadata.csv` maps filenames to identifiers, MIME types, and support information. All artwork is editable SVG source.

The SVG bases and generator are maintained in the adjacent `bases/` and `scripts/` directories of the project source.
