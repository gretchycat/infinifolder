# Syntax highlighting samples

Open 01/02/03 in the text viewer. Check comments, strings, keywords and numbers;
enter editing mode and type inside/outside a string or comment, then undo/redo,
search, save a copy and reopen. Text and selection must survive color updates.

Use **Aa → Text appearance** in the text viewer, or **Aa** in HTML/Markdown.
Choose Auto/Plain or a language; change global font, size and colors, then a token
style. Import `custom-text-theme.json` to test a shared descriptor, variable font
sizes/families and emphasis; export and reimport it. Preferences apply to source
viewing and editing in all three viewers. HTML/Markdown rendered previews retain
their existing presentation; switch to Source/Edit to see source highlighting.

Use 04/05 for HTML/Markdown source and 06–09 for more lexical conventions. These
small synthetic files can be copied for edits. Larger text remains subject to the
existing read-only guard; chunk highlighting uses bounded context after jumps.
