# Animation samples

Generated by `scripts/generate-animation-fixtures.py` using original artwork.
Open `motion-palette.fli`, `.flc`, `.gif`, `.webp`, `.apng`, and `.mng` in the
image viewer. Expect a moving ball, changing rainbow colors and frame counter,
with a brief intentional black frame halfway through. FLC pauses longer at
frame 51. Motion samples loop continuously in the player.
`stored-objects.mng` shows the same animation through hidden PNG objects,
grouped FRAM and SHOW commands.

`interactive-regions.mng` has two colored pointer regions. Touch/drag or hover a
mouse over either region, then leave it; the normal/left/right state should
follow the encoded events. **States…** provides direct selection and can disable
touch input to enable gallery swipes. Its input mask is a four-bit indexed PNG.

`recoverable-header.flc` deliberately lacks size/count/dimensions/default timing.
Its complete compressed rows/frames permit conservative recovery; expect a
recovery notice and a warning about fallback timing. The file is not rewritten.

`transparency-disposal.png` is also animated despite its ordinary PNG extension.
It exercises translucent composition and background/previous disposal. It stores
a two-play count, which the player's default continuous looping overrides.
`reference-frame-15.png` is a static reference.

Try play/pause, the timeline, pinch zoom, background/foreground, rotation and
swiping between files. GIF/WebP progress is read-only; custom animation timelines
allow seeking, including while paused.
Editing freezes a still frame. Listing icons should remain still thumbnails.

These are generated acceptance samples, not evidence of device verification.
